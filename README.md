# Privacy Policy – Pim

**Last updated:** 11-19-2026

Pim is a private moderation and administration bot operated by beejaay140ping for the Discord server Egypt Cafe. It is not offered to the public.

## What Pim processes

- **Message index:** message ID, channel ID, and author user ID only. Pim never stores message text in this index.
- **Moderation case records:** information parsed from the server’s moderation-log channel: case number, action, target user ID, moderator name, reason (limited to 200 characters), and relevant timestamps.
- **Bot action records:** moderator ID, action, target IDs, and time for actions taken through Pim.
- **Member-list exports:** exports requested by moderators are created in memory, sent only to the requesting moderator, and not stored.

## Why this data is used

The data helps server administrators moderate, review member history, and remove a user’s messages. It is used for nothing else.

## Sharing

Data is not sold or shared, used for advertising, or used to train AI or machine-learning models. Pim makes no calls to outside services.

## Storage and security

Data is stored in a database on a computer controlled by the developer. Only the developer has access.

## Retention and deletion

Data is kept while Pim is in the server. Message-index entries are removed when the corresponding message is deleted. To request deletion of your data, contact us using the information below.
